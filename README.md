## 📖 About the Project

The **She Can Foundation Website** is a responsive single-page website created to present the work and social impact of an NGO focused on women empowerment and community development.

The website helps visitors:

- Understand the foundation’s mission
- Explore its main focus areas
- Learn about community initiatives
- View stories of impact
- Become a volunteer
- Make a donation
- Contact the foundation
- Connect through social media

The project combines a soft, welcoming visual style with clear navigation and social-impact focused content.

## 🚀 How to Run the Project

### Method 1: Open Directly

1. Download the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your browser.

### Method 2: Clone with Git

```bash
git clone https://github.com/Rachana0106/she-can-foundation-website.git
```

Open the project folder:

```bash
cd she-can-foundation-website
```

Then open `index.html` in your browser.

### Method 3: Use VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Click **Open with Live Server**.

## ⚠️ Recommended Code Fixes

A few parts of the HTML should be corrected before presenting this as a polished project:

### Duplicate Font Awesome Link

Font Awesome is imported twice in the `<head>`. Keep only one link.

### Incorrect Closing Tags

These lines contain incorrect closing tags:

```html
<span class="contact-doodle-left">✿</di>
<span class="contact-doodle-right">♡</div>
```

Replace them with:

```html
<span class="contact-doodle-left">✿</span>
<span class="contact-doodle-right">♡</span>
```

### Missing Form Names

The form fields have placeholders but no `name` attributes. FormSubmit needs `name` values to identify submitted data.

Use:

```html
<input type="text" name="name" placeholder="Full Name" required>

<input type="email" name="email" placeholder="Email Address" required>

<input type="text" name="phone" placeholder="Phone Number">

<textarea name="message" placeholder="Message"></textarea>
```

### Empty Image Alt Text

Several images use:

```html
alt=""
```

Replace them with descriptive text such as:

```html
alt="Women empowerment community initiative"
```

This improves accessibility and SEO.
